# 04. 감자 시스템

- Phase: **MVP** (장비 태그, 먹이 도감 화면은 Phase 2)
- 관련: [03 이벤트](./03-events.md) · [02 관측 조건](./02-observing-conditions.md) · [10 알림](./10-notifications.md) · [01 명소](./01-spot-map.md)

## 목적
다녀온 경험을 기록하게 하고, 재방문 동기를 만든다. 감자는 명소에 사는 캐릭터이며 밤하늘의 것을 먹고 자란다. 방치하면 배고파하고 싹이 난다.

## 사용자 스토리
- 다녀온 사용자로서 후기와 사진을 남기면 그 명소에 내 감자가 생기길 바란다.
- 같은 곳을 또 간 사용자로서 감자가 커지는 걸 보고 싶다.
- 오래 안 간 사용자로서 큰 이벤트가 올 때 "감자가 배고파해요" 알림을 받고 싶다.
- 다른 사용자의 감자와 후기를 명소 상세에서 보고 참고하고 싶다.
- 개인 기록만 원하는 사용자로서 감자를 비공개로 두고 싶다.

## 규칙

### 심기와 먹이
- 감자는 **(사용자, 명소)당 하나**다. 같은 명소에 두 번째 기록을 남기면 새 감자가 아니라 기존 감자에 **먹이**가 추가된다.
- 기록 1건 = 먹이 1개. 기록 항목: 방문일(`visited_on`, 필수), 후기(2~2000자, 필수), 사진(0~5장), 공개 여부(감자 단위).
- `visited_on`은 오늘 이하, 2000-01-01 이상. 같은 감자에 같은 `visited_on`은 하루 1건만.
- 먹이 종류는 서버가 방문일 조건으로 결정한다. 우선순위:
  1. 방문일 밤에 이벤트가 있으면 → 유형에 따라 `meteor`(유성우) / `planet`(행성·혜성·기타) / `moon`(슈퍼문·월식). major 우선, 같으면 meteor > planet > moon.
  2. 방문일 밤 달 조도 ≥ 50% → `moon`.
  3. 명소 보틀 등급 ≤ 3 → `galaxy`.
  4. 그 외 → `star`.
- 먹이 종류는 도감·통계용이며 등급에는 영향이 없다.

### 등급
- `level = min(4, 먹이 수)`. Lv1 조랭이감자(첫 기록) → Lv2 감자 → Lv3 왕감자 → Lv4 별감자.
- 먹이를 삭제하면 재계산한다. 마지막 먹이를 삭제하면 감자도 삭제된다.

### 상태
- `normal` / `hungry` / `sprouted`. 등급과 독립.
- 매일 05:00 배치가 모든 감자를 재평가한다:
  - 기준 시각 T = 마지막 먹이의 `visited_on` 다음 날 + **7일 유예**.
  - T 이후 ~ 지금 사이에 극대기가 지난 `is_major` 이벤트 수 N (`visible_in_kr`만, 삭제 제외).
  - N = 0 → `normal`, N = 1 → `hungry`, N ≥ 2 → `sprouted`.
- `normal → hungry`로 바뀌는 순간 배고픔 알림을 1회 생성한다([10 알림](./10-notifications.md)). `hungry → sprouted`에서는 알림을 보내지 않는다(잔소리 방지).
- 먹이를 주면 즉시 `normal`. 등급은 떨어지지 않는다.
- 배고픔 알림 문구: "{명소}의 감자가 배고파해요. {다음 major 이벤트명}이 {D-day}에 와요." 다음 이벤트가 없으면 "{명소}의 감자가 배고파해요. 조건 좋은 밤에 다시 가볼까요?"

### 공개 범위
- 감자 단위 `is_public`. 기본 공개. 심을 때와 이후 언제든 변경.
- 공개 감자: 명소 상세 목록, (Phase 3) 피드에 노출. 명소의 `potato_count`는 공개 감자만 센다.
- 비공개 감자: 본인 감자밭에서만. 후기·사진도 비공개.

### 표시
- 일러스트: 등급 4 × 상태 2(normal / sprouted). `hungry`는 normal 일러스트 + 말풍선. 최소 8장 + 먹이 아이콘 5종.
- 내 감자밭(`/me/potatoes`): 감자 카드(일러스트, 명소명, 등급, 상태, 마지막 방문일, 먹이 수). 정렬: 상태(hungry·sprouted 우선) → 최근 방문.
- 감자 상세: 먹이(기록) 목록 최신순, 각 기록의 후기·사진·먹이 아이콘. 기록 수정·삭제.

## API
- `POST /api/v1/spots/{id}/potato/feeds` (auth) → 감자 없으면 생성. 응답에 `potato{level, state, food}`와 `is_new_potato`.
- `GET /api/v1/me/potatoes` · `GET /api/v1/potatoes/{id}` (본인 또는 공개) · `PATCH /api/v1/potatoes/{id}` (`is_public`).
- `PATCH /api/v1/feeds/{id}` · `DELETE /api/v1/feeds/{id}` (본인).
- `GET /api/v1/spots/{id}/potatoes?cursor=` → 공개 감자 목록(등급·상태·최신 후기 발췌·닉네임).

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| 방문일이 미래 | 400 `VISIT_DATE_IN_FUTURE` |
| 같은 감자·같은 방문일 재기록 | 409 `FEED_ALREADY_EXISTS`, 기존 기록 수정으로 안내 |
| 방문일이 오래전(예: 2019년) | 허용. 먹이 결정 시 그날 이벤트가 DB에 없으면 이벤트 규칙은 건너뛰고 달·보틀·별로 결정 |
| 명소 보틀 등급이 아직 없음(null) | galaxy 규칙 건너뜀 |
| 심은 직후 이틀 뒤가 major 이벤트 | 7일 유예 안이라 세지 않음. `normal` 유지 |
| 유예 후 major 이벤트 1개 지나 `hungry`, 사용자가 먹이 안 주고 또 1개 지남 | `sprouted`, 추가 알림 없음 |
| `sprouted` 상태에서 먹이 | `normal`로 즉시 회복, 등급 +1 |
| Lv4에서 먹이 | 등급 유지, 먹이 수만 증가. 응답에 `level_up: false` |
| 기록 수정으로 `visited_on`이 바뀜 | 먹이 종류 재결정, 상태는 다음 배치에서 재평가(즉시 재평가도 수행) |
| 마지막 먹이 삭제 | 감자 삭제, 사진 오브젝트 삭제 예약 |
| 감자가 비공개인데 URL로 타인이 접근 | 404 (존재 여부 노출 안 함) |
| 명소가 `hidden` 처리됨 | 감자·기록 유지. 감자밭에 "비공개 처리된 명소" 표시. 명소 상세 접근 불가 |
| 명소가 `under_review` | 정상 표시 |
| 사용자 탈퇴 | 감자·기록·사진 즉시 삭제 |
| 사진 5장 초과 | 400 `TOO_MANY_PHOTOS` |
| 사진 URL이 우리 스토리지 도메인이 아님 | 400. presign으로 받은 키만 허용 |
| 후기에 URL·연락처 | MVP는 허용. 신고 기능은 Phase 2 커뮤니티와 함께 |
| 배치 실행 중 실패 | 감자 단위 트랜잭션. 실패한 감자는 로그, 다음 날 재시도 |
| 배치가 하루 두 번 실행됨(재배포 등) | 멱등. 상태 변화 없으면 알림도 없음 |
| major 이벤트가 삭제·minor로 변경됨 | 다음 배치에서 N이 줄어 상태가 되돌아갈 수 있음. 이미 보낸 알림은 유지 |
| 같은 사용자가 두 기기에서 동시에 첫 기록 | (user, spot) 유니크 제약으로 한쪽은 기존 감자에 먹이로 처리 |

## 완료 기준

**MVP**
- [ ] `potato/service/PotatoService`에 먹이 결정 우선순위 4단계, 등급 계산, 상태 전이(유예·N 카운트·알림 1회)의 JUnit 테스트가 있다(최소 20케이스).
- [ ] 로그인 사용자가 명소 상세에서 기록을 남기면 감자가 생기고, 두 번째 기록에서 Lv2가 된다.
- [ ] 내 감자밭에 감자 카드가 상태 우선 정렬로 보인다.
- [ ] 비공개 감자는 명소 상세와 카운트에서 빠지고 타인 접근 시 404.
- [ ] 배치를 수동 실행했을 때 테스트 데이터의 감자가 `hungry`가 되고 알림 1건이 생기며, 다시 실행해도 알림이 늘지 않는다.
- [ ] 일러스트 8장과 먹이 아이콘 5종이 적용되어 있다.
- [ ] 사진 업로드(presign → PUT → 기록 저장) 흐름이 모바일 브라우저에서 동작한다.

**Phase 2+**
- [ ] 기록에 장비 태그, 먹이 도감 화면, 명소별 감자 랭킹.

## 미결
- 유예 7일, N 임계값 1/2의 실측 튜닝.
- 감자에 이름 붙이기 기능 여부.
- 명소당 감자 하나 규칙이 "여러 번 가면 감자가 많아지길" 기대하는 사용자와 충돌하는지 베타에서 확인.
