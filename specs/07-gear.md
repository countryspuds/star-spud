# 07. 장비

- Phase: **MVP 제외.** 큐레이션 가이드·감자 장비 태그는 Phase 2, 사용자 후기·순위는 Phase 3.
- 관련: [04 감자](./04-potato.md) · [09 관리자](./09-admin.md)

## 목적
입문자가 첫 장비를 고르게 돕고, 실제 관측 기록에서 장비별 후기가 자연스럽게 쌓이게 한다. 제휴·판매는 없다.

## 구성

### 7.1 장비 마스터
```
gear  id, category(binoculars|telescope|mount|camera|lens|tripod|accessory|app),
      name, brand, model, price_band(under_10|10_30|30_100|over_100 만원), spec(json),
      status(active|discontinued|pending), created_by(관리자|사용자 제안), created_at
```
- 관리자가 등록. 사용자는 "없는 장비 제안"으로 `pending` 생성 가능, 관리자 승인 시 `active`.
- 중복 방지: 브랜드+모델 정규화(소문자·공백 제거) 유니크.

### 7.2 큐레이션 가이드 (Phase 2)
- 관리자가 작성하는 문서형 콘텐츠: "10만원 이하 첫 쌍안경", "스마트폰으로 은하수 찍기" 등.
- 각 가이드는 장비 마스터 항목을 카드로 참조한다. 가격은 밴드만 표시(실시간 가격 없음).
- 목록·상세 페이지. 검색 없음.

### 7.3 감자 장비 태그 (Phase 2)
- 감자 기록 작성 시 사용 장비를 마스터에서 검색해 0~5개 태그(`potato_feed_gear`).
- 장비 상세 페이지에 그 장비를 태그한 공개 기록이 모인다. 명소·조건·사진과 함께 보이므로 "이 장비로 어디서 뭘 봤나"가 된다.

### 7.4 사용자 후기·순위 (Phase 3)
- 장비당 사용자 1건 평점(1~5) + 후기(≤2000자) + 장점/단점 + 사용 기간.
- 순위: 카테고리·가격 밴드별 평점 평균(후기 5건 이상만), 베이지안 보정.
- 후기와 태그 기록 수를 함께 표시.

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| 사용자가 제안한 장비가 기존과 중복 | 정규화 유니크로 409, 기존 항목으로 안내 |
| 단종 장비 | `discontinued` 배지, 태그·후기는 계속 가능, 가이드에서는 자동 제외 |
| 후기 5건 미만 | 순위에 미포함, "후기 모으는 중" |
| 한 사용자가 여러 계정으로 평점 | 계정 단위로만 제한. 어뷰징 대응은 관리자 신고 처리 |
| 장비가 pending 상태인데 태그하려 함 | 태그 허용(본인 기록에만 보임), 승인 후 공개 집계 |
| 관리자가 장비를 삭제 | 소프트 삭제. 태그·후기는 "삭제된 장비"로 표시 |
| 가격 밴드가 시간이 지나 안 맞음 | 관리자가 수정. 이력은 두지 않음 |

## 완료 기준

**Phase 2**
- [ ] 장비 마스터 CRUD(관리자), 사용자 제안·승인 흐름, 중복 정규화 테스트.
- [ ] 가이드 3편 이상 게시, 장비 카드 참조.
- [ ] 감자 기록에 장비 태그, 장비 상세에 태그 기록 집계.

**Phase 3**
- [ ] 후기·평점·순위 계산 테스트(5건 미만 제외, 보정식).

## 미결
- 스마트폰·앱(천체 앱)을 장비 카테고리에 넣을지.
- 순위 보정식(베이지안 평균의 사전값).
