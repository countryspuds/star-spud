# 06. 커뮤니티

> **2026-11-01 디자인 메모.** 화면 디자인이 캔버스에 있다(피드·글 상세·글쓰기·수정·삭제 확인). 디자인 기준 용어: 글 종류 5개 = 후기·질문·**모임**(번개 모임 대신)·사진 응모·잡담. 명소 태그에 오늘 밤 지수 표시, 투표, 우주 뉴스 칸, 글 수정 시 "(수정됨)" 표시, 삭제는 30일 소프트 삭제(감자·응모는 유지). 이 명세를 구현할 때 아래 내용과 디자인이 다르면 디자인 쪽 용어를 따르고 이 문서를 고친다.

- Phase: **MVP 제외.** 명소 스레드·자유 게시판은 Phase 2, 번개 모임·팔로우·피드는 Phase 3.
- 관련: [04 감자](./04-potato.md) · [03 이벤트](./03-events.md) · [09 관리자](./09-admin.md)

## 목적
같은 명소·같은 이벤트에 관심 있는 사람을 연결한다. 공개 감자가 곧 명소 후기이므로 커뮤니티는 감자 위에 얹는 형태로 만든다.

## 구성

### 6.1 명소별 스레드 (Phase 2)
- 명소 상세 하단. 두 가지 항목이 섞여 시간순으로 보인다: 공개 감자 기록(읽기 전용, 감자에서 관리) + 질문 글.
- 질문 글: 제목 없이 본문(≤1000자) + 사진 0~3장. 댓글(≤500자).
- 답변 채택 없음. 좋아요만.

### 6.2 자유 게시판 (Phase 2)
- 카테고리: 질문 / 사진 / 잡담 / 정보. 제목(≤80자) + 본문(≤5000자) + 사진 0~10장.
- 댓글·대댓글(1단계). 좋아요.
- 목록: 최신순 기본, 카테고리 필터, 검색(제목·본문).

### 6.3 번개 모임 (Phase 3)
- 특정 이벤트 + 명소 + 날짜시각에 "같이 갈 사람" 모집. 관측 장인 세션도 이 형태로 열린다(장비 보유 표시 필드).
- 필드: 이벤트(선택), 명소(필수), 만나는 시각, 정원(2~20), 소개, 준비물, 호스트 장비 보유 여부.
- 참가 신청 → 호스트 승인 → 확정. 취소는 만남 24시간 전까지 자유, 이후는 호스트에게 알림.
- 모임 채팅은 두지 않는다. 댓글로 대체.
- 필수 안전 고지: 야간·산간 활동 위험, 미성년자 보호자 동반, 서비스는 만남을 중개하지 않는다는 문구. 모집 글 작성 시 동의.

### 6.4 팔로우·피드 (Phase 3)
- 사용자 프로필(닉네임, 아바타, 공개 감자 수, 등급 합계).
- 팔로우 → 피드(`/feed`)에 팔로우한 사용자의 공개 감자 기록이 시간순으로.
- 차단: 차단한 사용자의 글·댓글·감자가 나에게 보이지 않고, 그 사용자도 내 콘텐츠를 볼 수 없다.

### 공통: 신고·제재
- 모든 UGC(글·댓글·모임·메모·감자 기록)에 신고. 사유: 스팸 / 욕설 / 허위 정보 / 위험 행위 / 기타.
- 같은 대상에 신고 3건 → `under_review`, 관리자 큐로. 관리자가 숨김·복구·작성자 제재(경고 / 7일 정지 / 영구).
- 작성 속도 제한: 글 분당 2건, 댓글 분당 5건. 초과 시 429.

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| 글 작성자가 탈퇴 | 글·댓글 유지, 작성자 "탈퇴한 사용자". 사진은 유지(공개 콘텐츠) |
| 감자 기록을 비공개로 전환 | 명소 스레드·피드에서 즉시 사라짐. 그 기록에 달린 댓글은 작성자에게만 보임 |
| 모임 호스트가 탈퇴·취소 | 모임 자동 취소, 참가자 전원 알림 |
| 모임 정원 초과 신청 | 대기 없이 거절. "정원이 찼어요" |
| 만남 시각이 지난 모임 | 자동 `ended`. 신청 불가 |
| 모임 명소가 hidden 처리됨 | 모임 상세에 경고, 호스트에게 알림 |
| 차단한 사용자가 내 모임에 신청 | 목록에 보이지 않고 자동 거절 |
| 신고 3건이 같은 사용자의 중복 신고 | 사용자당 대상당 1건. 3건은 서로 다른 사용자 |
| 신고 대상이 이미 숨김 | 409 |
| 제재 중인 사용자 | 읽기 가능, 쓰기 API 403 `USER_SUSPENDED` + 종료일 |
| 미성년자 | 나이를 수집하지 않으므로 판별 불가. 안전 고지로 대체 |
| 게시글 본문에 외부 링크 | 허용. `rel="nofollow"`로 렌더 |
| 이미지 10장 모두 업로드 후 저장 실패 | 고아 오브젝트는 24시간 후 정리 배치 |
