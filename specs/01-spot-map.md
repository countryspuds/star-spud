# 01. 명소 지도

- Phase: **MVP** (사용자 명소 등록은 MVP 후반, 시간 허용 시)
- 관련: [ADR-0001 카카오맵](../docs/ADR/0001-kakao-map-sdk.md) · [ADR-0002 광공해](../docs/ADR/0002-light-pollution-viirs.md) · [02 관측 조건](./02-observing-conditions.md)

## 목적
사용자가 지도에서 관측 명소를 찾고, 선택한 날짜의 관측 조건을 핀 색으로 한눈에 비교한 뒤 명소 상세로 들어가게 한다.

## 사용자 스토리
- 입문자로서 지도를 열면 내 주변 명소와 오늘 밤 상태가 색으로 보여서 어디 갈지 바로 고르고 싶다.
- 차박족으로서 차박 가능·화장실 있음으로 걸러서 보고 싶다.
- 취미가로서 보틀 등급 4 이하만 보고, 남쪽 하늘이 트인 곳인지 알고 싶다.
- 명소를 아는 사용자로서 지도에 없는 곳을 직접 등록하고 싶다.

## 기능 상세

### 지도 화면
- 카카오맵 JS SDK. 초기 뷰: 위치 권한 허용 시 현재 위치 중심 줌 10, 거부·미응답 시 대한민국 전체 뷰.
- 상단: 날짜 선택(오늘 / 내일 / 모레), 검색창(명소명·지역명), 필터 버튼, 광공해 오버레이 토글.
- 핀: 명소 유형 아이콘 + 조건 색상. 색상은 API의 `condition` 값(`good` 초록 / `fair` 노랑 / `bad` 회색 / `unknown` 흰색 테두리)으로만 결정한다. 프론트는 판정하지 않는다.
- 줌 9 이하에서는 핀을 클러스터링한다(카카오맵 MarkerClusterer). 클러스터 색은 포함 핀 중 가장 좋은 조건.
- 핀 탭 → 하단 시트(모바일) / 사이드 패널(데스크톱)에 요약: 이름, 유형, 보틀 등급, 오늘 구름·달, 공개 감자 수, 필터 아이콘(차박·주차·화장실). "상세 보기" 버튼.
- 지도 이동·줌 종료 시 현재 bbox로 명소를 다시 조회한다. 디바운스 300ms.

### 필터
- 유형(복수): 자연 / 천문대 / 캠핑장 / 도심 근교.
- 편의: 차박 가능, 주차 가능, 화장실.
- 보틀 등급 최대값(1~9 슬라이더, 기본 9).
- 조건: "오늘 좋은 곳만".
- 필터는 URL 쿼리에 반영되어 공유·새로고침에 유지된다.

### 명소 상세 (`/spots/:id`)
- 사진(없으면 유형별 기본 이미지), 이름, 유형, 주소(역지오코딩), 설명.
- 관측 조건 카드: [02 관측 조건](./02-observing-conditions.md)의 상세 표시.
- 정보 표: 보틀 등급(추정 문구), 접근성, 포장 여부, 차박, 주차, 화장실, 시야 개방 방향과 지평선 고도.
- 길찾기 버튼: [05 경로](./05-routes.md).
- 이 명소의 공개 감자 목록(최신순, 등급 일러스트 + 후기 발췌). 로그인 시 "감자 심기" 버튼.
- 신고 버튼(로그인 필요).
- 출처가 `ugc`이면 "사용자 등록 명소" 배지와 등록자 닉네임.

### 광공해 오버레이
- 토글 시 정적 타일(`lp/{z}/{x}/{y}.png`, z 6~12)을 반투명(0.5) 타일셋으로 얹는다.
- 범례(색상 → 보틀 등급 대략) 표시.
- 타일이 없는 줌 레벨에서는 가장 가까운 레벨을 확대해 쓴다(카카오맵 타일셋 기본 동작). 없으면 표시하지 않는다.

### 명소 데이터
- 초기 데이터: 운영자 큐레이션 약 30곳. `backend/scripts/seed_spots.py`에서 YAML/CSV로 적재.
- 저장 시 위경도 → 기상청 격자(x, y) 변환값을 함께 저장한다.
- 보틀 등급은 VIIRS 샘플링 스크립트가 채운다. 값이 없으면 상세에 "측정 전" 표시.

### 사용자 명소 등록 (MVP 후반)
- 로그인 필요. 지도 길게 누르기 또는 "명소 등록" 버튼 → 지도에서 위치 찍기 → 폼(이름, 유형, 접근성, 편의, 시야 개방, 설명, 사진 최대 5장).
- 저장 즉시 `active`로 공개. `source = ugc`, `created_by` 기록.
- 신고가 3건 누적되면 `status = under_review`로 바뀌고 지도에서는 "검토 중" 배지로 계속 보인다. 관리자가 `active` 또는 `hidden`으로 결정한다.
- 등록자는 자기 명소를 수정할 수 있다. 다른 사용자의 감자가 심긴 뒤에는 위치를 옮길 수 없다.

## API (요약)
- `GET /api/v1/spots?bbox=&date=&types=&car_camping=&parking=&toilet=&max_bortle=&good_only=` → 핀 목록(`id, name, type, lat, lng, bortle, condition, potato_count, flags`). 최대 500건. 초과 시 `truncated: true`.
- `GET /api/v1/spots/{id}?date=` → 상세 + 조건.
- `GET /api/v1/spots/search?q=` → 이름·주소 검색 상위 10건.
- `POST /api/v1/spots` (auth) · `PATCH /api/v1/spots/{id}` (등록자·관리자) · `POST /api/v1/spots/{id}/reports` (auth).
- `POST /api/v1/uploads/presign` (auth) → 사진 업로드용 presigned URL.

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| 위치 권한 거부 | 전국 뷰. 다시 묻지 않고 "내 위치" 버튼으로만 재요청 |
| 카카오맵 SDK 로드 실패(키 오류·네트워크) | 지도 영역에 오류 문구 + 명소 목록 뷰로 대체 |
| bbox 안 명소가 500건 초과 | 500건까지만 반환하고 "확대해서 더 보기" 안내 |
| 명소에 날씨 스냅샷이 없음(신규 등록 직후, 격자 변환 실패) | `condition = unknown`, 핀 흰색, 상세에 "조건 정보 준비 중" |
| 스냅샷이 6시간 이상 오래됨(기상청 장애) | 조건은 표시하되 "N시간 전 예보" 문구 |
| 등록 위치가 대한민국 bbox(위도 33~39, 경도 124~132) 밖 | 400 `SPOT_OUT_OF_BOUNDS` |
| 등록 위치 반경 200m 안에 기존 명소 존재 | 저장 전 "이미 있는 명소가 아닌가요?" 경고와 기존 명소 링크. 확인하면 저장 |
| 같은 이름의 명소 | 허용. 이름은 유니크가 아님 |
| 명소가 `hidden` 상태 | 지도·검색·목록에서 제외. 직접 URL 접근 시 404. 심긴 감자는 감자밭에 "비공개 처리된 명소"로 유지 |
| `under_review` 명소 | 지도에 표시하되 배지. 추천·"좋은 곳만" 필터에서는 제외 |
| 사진 업로드 도중 실패 | 명소는 사진 없이 저장 가능. 업로드 실패한 항목만 재시도 |
| 사진 형식이 HEIC | 클라이언트에서 JPEG로 변환 후 업로드. 변환 불가 시 거부 안내 |
| 광공해 타일 요청이 404 | 무시. 콘솔 에러 없이 빈 타일 |
| 오프라인 | 지도 타일은 SDK 기본 동작. 명소 API 실패 시 마지막 응답 유지 + 토스트 |
| 날짜를 모레로 바꿨는데 일부 명소는 모레 예보가 아직 없음 | 해당 명소만 `unknown` |
| 신고자가 같은 명소를 반복 신고 | 사용자당 명소당 1건. 재시도 시 409 |
| 등록자가 탈퇴 | 명소는 유지, `created_by`는 null, 배지는 "사용자 등록 명소"만 |

## 완료 기준

**MVP**
- [ ] 비로그인으로 지도를 열면 큐레이션 30곳이 핀으로 보이고, 날짜 선택에 따라 핀 색이 바뀐다.
- [ ] 필터 4종이 동작하고 URL에 반영된다.
- [ ] 핀 탭 → 요약 → 상세 페이지 이동이 모바일·데스크톱에서 동작한다.
- [ ] 상세 페이지에 정보 표 8개 항목과 조건 카드, 공개 감자 목록이 보인다.
- [ ] 30곳 전부 보틀 등급이 채워져 있다(VIIRS 샘플링).
- [ ] `GET /spots` bbox 조회가 30곳 기준 300ms 이내(로컬).
- [ ] 위 엣지 케이스 중 위치 권한 거부, 스냅샷 없음, hidden 명소, bbox 밖 등록에 대한 테스트가 있다.
- [ ] (스트레치) 광공해 오버레이 토글이 동작하고 범례가 있다.
- [ ] (후반) 명소 등록 폼으로 등록한 명소가 즉시 지도에 나타나고, 신고 3건이면 `under_review`가 된다.

**전체**
- [ ] 공공데이터(천문대·캠핑장) 수입 스크립트와 중복 병합 규칙.
- [ ] 클러스터링, 검색 자동완성, 상세의 진입로 메모([05](./05-routes.md)).
