# 09. 관리자

- Phase: **MVP는 최소 관리자 REST API + 프론트 관리 화면.** 신고 큐·감사 로그는 Phase 2.
- 관련: [ADR-0010](../docs/ADR/0010-admin-sqladmin.md) · [01 명소](./01-spot-map.md) · [03 이벤트](./03-events.md) · [06 커뮤니티](./06-community.md)

## 목적
두 명의 운영자가 데이터를 직접 고치지 않고도 명소·이벤트·신고·제재를 처리하게 한다.

## 기능 상세

### MVP (`/api/v1/admin/*` + 프론트 `/admin`)
- 인증: 관리자 `role`인 사용자만. 카카오 로그인으로 받은 JWT의 역할을 확인하거나, 별도 관리자 비밀번호(환경 변수)로 관리자 세션 생성. MVP는 후자.
- 관리 대상 모델과 권한 (API는 목록·상세·편집 엔드포인트, 화면은 표 + 편집 폼):

| 모델 | 목록 컬럼 | 편집 | 비고 |
|---|---|---|---|
| spots | 이름, 유형, 상태, 출처, 보틀, 신고 수 | 전체 | 상태 변경(active/under_review/hidden), 좌표 편집 시 격자 재계산 |
| spot_reports | 명소, 사유, 신고자, 처리일 | resolved_at | 처리 시 명소 상태를 함께 결정 |
| events | 이름, 유형, 극대기, major, 한국 관측 | 전체 | `visible_in_kr=false`면 major 불가 검증 |
| users | 닉네임, 제공자, 역할, 가입일, 제재 | role, 제재 | 삭제 불가(탈퇴 API로만) |
| potatoes / potato_feeds | 읽기 전용 | 삭제만 | 신고 대응용 |
| notifications | 읽기 전용 | — | 디버깅 |

- 액션 엔드포인트: 명소 "보틀 등급 재샘플링", 이벤트 "감자 배치 즉시 실행", 사용자 "7일 정지 / 해제".

### Phase 2
- 신고 큐 화면: 미처리 신고를 대상별로 묶어 표시, 한 화면에서 숨김·복구·제재.
- 장비 마스터·가이드 편집, 사용자 제안 승인.
- 감사 로그: 관리자 행위(누가·언제·무엇을) 기록. 되돌리기는 없음.
- 대시보드: 일별 가입·감자·기록 수, 스냅샷 갱신 실패 수.

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| 관리자가 명소를 삭제 | 삭제 버튼 없음. `hidden`만 가능 |
| 관리자가 자기 역할을 user로 변경 | 마지막 관리자면 거부 |
| 명소 좌표 편집으로 격자가 바뀜 | 저장 시 서비스에서 격자 재계산, 스냅샷 즉시 갱신 시도 |
| 이벤트 극대기를 과거로 수정 | 허용. 감자 배치가 다음 실행에서 반영 |
| 관리자 비밀번호 노출 의심 | 환경 변수 교체로 전체 세션 무효 |
| `/admin`·`/api/v1/admin/*`에 비관리자 접근 | 404 (존재 노출 안 함) |
| 신고 처리 후 명소 상태를 안 바꿈 | 처리 시 상태 선택 필수 |

## 완료 기준

**MVP**
- [ ] `/admin`에서 명소·이벤트·신고·사용자가 보이고 편집된다.
- [ ] 이벤트 major 검증, 명소 좌표 편집 시 격자 재계산 테스트.
- [ ] 마지막 관리자 강등 방지 테스트.
- [ ] 비관리자 접근 404 (API·화면 모두).

**Phase 2**
- [ ] 신고 큐, 감사 로그, 대시보드.

## 미결
