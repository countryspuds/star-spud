# 05. 경로

- Phase: **MVP는 카카오맵 딥링크만.** 앱 내 경로 표시와 진입로 메모는 Phase 2.
- 관련: [01 명소 지도](./01-spot-map.md) · [ADR-0001](../docs/ADR/0001-kakao-map-sdk.md)

## 목적
명소까지 가는 길과, 지도 앱이 알려주지 않는 현장 정보(비포장 구간, 차단기, 주차 후 도보)를 제공한다.

## 사용자 스토리
- 처음 가는 사용자로서 상세에서 버튼 하나로 길찾기를 시작하고 싶다.
- 산길 명소를 가는 사용자로서 마지막 구간이 비포장인지, 밤에 차단기가 닫히는지 미리 알고 싶다.
- 다녀온 사용자로서 진입로 정보를 남겨 다음 사람을 돕고 싶다.

## 기능 상세

### MVP: 길찾기 딥링크
- 명소 상세의 "길찾기" 버튼 → 카카오맵 앱 스킴(`kakaomap://route?ep={lat},{lng}&by=CAR`). 앱이 없거나 데스크톱이면 카카오맵 웹 길찾기 URL로 새 탭.
- 출발지는 지정하지 않는다(카카오맵이 현재 위치 사용).
- 앱 설치 감지: 스킴 호출 후 1.5초 안에 페이지가 숨겨지지 않으면 웹 URL로 폴백.

### Phase 2: 앱 내 경로
- 카카오모빌리티 길찾기 API를 서버가 프록시(`GET /api/v1/routes?from=&to_spot=`). 응답: 거리, 소요 시간, 경로 폴리라인, 통행료.
- 지도에 폴리라인을 그리고 상세 카드에 거리·시간. "카카오맵에서 안내 시작" 버튼은 유지.
- 캐시: 같은 출발 격자(500m)·명소 조합은 10분 캐시.
- 출발지 기본은 현재 위치, 권한이 없으면 주소 검색 입력.

### Phase 2: 진입로 메모
```
spot_notes  id, spot_id, user_id, category(road|parking|gate|safety|other), body(≤300자),
            helpful_count, created_at, updated_at, status(active|hidden)
```
- 명소 상세 "가는 길 메모" 섹션. 카테고리 아이콘 + 본문 + 작성일 + "도움돼요" 버튼.
- 정렬: 도움돼요 수 → 최신. 상위 3개만 펼치고 나머지 접기.
- 작성자만 수정·삭제. 신고 가능(커뮤니티 신고 체계 공유).

## 엣지 케이스
| 상황 | 동작 |
|---|---|
| iOS Safari에서 스킴 호출이 "잘못된 주소" 알림을 띄움 | 유니버설 링크가 없으므로 웹 URL을 기본으로 하고, 앱 열기는 사용자 선택 버튼으로 분리 |
| 명소 좌표가 도로에서 멀리 떨어진 산속(Phase 2) | 길찾기 API가 가장 가까운 도로 지점까지 안내. 응답의 종점과 명소 거리가 300m 이상이면 "여기서부터 도보 약 N분" 표시 |
| 길찾기 API 실패·쿼터 초과 | 딥링크 버튼만 노출, 오류 토스트 |
| 위치 권한 없음(Phase 2) | 출발지 검색 입력으로 대체 |
| 메모가 오래됨(1년 이상) | "1년 전 정보" 배지 |
| 같은 사용자가 메모를 여러 개 | 카테고리당 1개 |
| 메모 작성자 탈퇴 | 메모 유지, 작성자 "탈퇴한 사용자" |
| 통행 불가 정보(도로 폐쇄) | `gate`/`safety` 카테고리 메모가 최근 30일 안에 3건 이상 도움돼요를 받으면 상세 상단에 경고 배너 |

## 완료 기준

**MVP**
- [ ] 안드로이드 크롬·iOS 사파리·데스크톱에서 길찾기 버튼이 각각 앱 또는 웹 길찾기로 이어진다.
- [ ] 폴백 로직 단위 테스트(타이머 기반)는 두지 않고 수동 검증 체크리스트를 PR에 첨부한다.

**Phase 2**
- [ ] 경로 프록시 API와 캐시 테스트, 폴리라인 표시, 도보 구간 안내.
- [ ] 진입로 메모 CRUD, 도움돼요, 카테고리당 1개 제약 테스트, 경고 배너.
