## 1. 제품 개요

**한 줄 정의.** 별 보기 좋은 곳을 *어디·언제* 가야 할지 알려주고, 다녀온 기록을 '감자' 캐릭터로 키우는 천체관측 플랫폼.

**해결하는 문제.**
- 별을 보러 가고 싶지만 어디로, 언제 가야 하는지 모른다. (장소·타이밍 정보가 블로그에 흩어져 있음)
- 막상 갔는데 구름·달빛·광공해 때문에 허탕 친다. (조건 판단이 어려움)
- 다녀온 경험이 사진첩에 묻히고 다시 갈 동기가 없다. (기록·리텐션 부재)

**핵심 가치 순서.**
1. 오늘 밤(또는 이번 주말) 어디 가면 별이 보이는가 — **별보기 지도**(5 km 도트 격자 점수, [specs/11](../specs/11-star-score.md)) + 명소 지도 + 관측 조건
2. 언제 가야 하는가 — **천문 캘린더**([specs/12](../specs/12-calendar.md)) + 홈의 10일 별보기 지수
3. 다녀온 기록과 재방문 동기 — 감자 시스템

**시각 정체성.** 5 km 격자 도트(광공해·별보기 점수), 픽셀 감자·픽셀 달, 짙은 남청 바탕의 벤토 카드. 홈은 "오늘 밤 어디 갈까"에 한 화면으로 답하는 벤토 랜딩이다([ADR-0012](./ADR/0012-home-and-ia.md)).

**비즈니스.** 당분간 무료 서비스. 수익 모델 없음. 사용자 확보가 우선.

## 2. 타겟 사용자

| 페르소나 | 니즈 | 서비스에서의 위치 |
|---|---|---|
| **입문자·나들이족** (데이트, 가족, 첫 별 구경) | "오늘 밤 갈 만한가"를 한눈에. 전문 용어 없이 | **첫 화면의 주인공.** 단일 판정·직관적 색상 |
| **차박·캠핑 애호가** | 밤새 머물 수 있고 별도 좋은 곳. 화장실·주차 | 명소 필터(차박·주차·화장실)와 캠핑장 명소 유형 |
| **천체사진·관측 취미가** | 보틀 등급, 박명 시각, 시야 개방도, 달 출몰 | 명소 상세와 조건 상세에 데이터로 제공 |

세 그룹을 모두 대상으로 하되, 첫 화면과 기본 판정 기준은 입문자에게 맞춘다. 취미가용 정보는 숨기지 않고 상세 화면에 배치한다.

## 4. MVP 경계

**목표.** 2026-12-01 베타 공개 (12월 중순 쌍둥이자리 유성우 전). 팀 2인.

**Phase 1 완료 기준(루프).** 로그인 → 홈에서 오늘 밤 답을 봄 → 지도/캘린더에서 명소 선택 → 명소 상세(진입로·주차) → 다녀와서 감자 심기(사진+후기) → 내 감자밭에 보임 → 이달의 사진 후보. 이 루프에서 끊기는 지점이 하나라도 있으면 미완.

| 영역 | MVP 포함 | MVP 제외 (Phase 2+) |
|---|---|---|
| 홈 | 벤토 랜딩(이달의 사진 · 별보기 위젯 · 10일 지수 · 세부값 · 이벤트 3개) | — |
| 별보기 지도 | 5 km 격자 점수, 광공해 탭, 시·도 → 시·군·구 퍼즐, 내 감자밭 탭 | 1 km·500 m 격자, 접근성(도로망) 요소 |
| 명소 지도 | 4개 유형, 큐레이션 30곳(17 시·도 × 2곳 이상), 필터, 핀 조건 색상, 내 위치 기준 | 공공데이터 대량 수입 |
| 명소 등록(UGC) | 후반에 시간 허용 시 (즉시 공개 + 신고) | — |
| 광공해 | 좌표 샘플링으로 명소별 보틀 등급 (필수), 정적 타일 오버레이 (스트레치) | — |
| 관측 조건 | 구름량·달·박명, 오늘~+2일, 좋은 날 판정, 홈 10일 지수 | 시정·습도·바람, 날씨·지형고도 지도 탭(placeholder만) |
| 캘린더·이벤트 | KASI 4종 연동, 월별 캘린더(출몰·달 조도·현상·촬영 적기 띠), 이벤트 자동 적재 | 사용자 알림 설정, 은하수 출몰시각 |
| 감자 | 심기(후기·사진·공개범위), 먹이·등급, 방치 상태, 내 감자밭 | 장비 태그, 먹이 도감 화면 |
| 알림 | 앱 내 알림함 (배고픔 알림) | 푸시(FCM), 이메일 |
| 경로 | 카카오맵 앱 딥링크만 | 앱 내 경로 표시, 진입로 메모 |
| 커뮤니티 | 메뉴 + 준비 중 페이지 (명소 상세의 공개 감자 목록이 사실상 후기) | 피드·모임·투표·잡담·우주 뉴스·팔로우 (디자인 완료) |
| 장터·장비 | 메뉴 + 준비 중 페이지 | 중고 장터(채팅 연결) · 장비 가이드 (디자인 완료) |
| 인증 | 카카오 + 온보딩(닉네임·감자 아바타·지역) | 네이버·이메일(디자인 완료)·구글·애플 |
| 프로필 | 감자밭 · 설정(닉네임·아바타·지역) | 활동 탭, 프로필 사진 업로드, 계정 연결 |
| 문의 | 접수 폼 + DB + 관리자 이메일 알림 | 상태 관리 화면, 제안 감자 |
| 관리자 | 관리자 API + 최소 관리 화면 | 신고 큐·감사 로그·대시보드 |
| 클라이언트 | 반응형 웹 | 네이티브 앱 |

**MVP 성공 기준.**
- 비로그인 사용자가 지도에서 30곳의 오늘 밤 조건을 보고 명소 상세까지 도달한다.
- 로그인 사용자가 감자를 심고, 내 감자밭에서 등급과 상태를 본다.
- 이벤트가 지나가면 배치가 감자를 배고픔 상태로 바꾸고 알림함에 항목이 생긴다.
- 백엔드 `./gradlew test` 통과, 프론트 lint·타입 검사 통과, PaaS에 배포되어 외부 접속 가능.

**월별 마일스톤.**

| 기간 | 목표 | 검증 |
|---|---|---|
| 2026-09 | 골격(TS 전환, backend app 구조, docker), spots 모델 + 30곳 시드, 카카오맵 핀, 기상청 연동·스냅샷 | 지도에 30곳 핀과 오늘 밤 구름량 |
| 2026-10 | 달·박명 계산(KASI), 조건 화면 + 날짜 선택, 카카오 로그인, 감자 심기(사진 업로드) | 로그인 후 감자 심고 내 감자밭 확인 |
| 2026-11 | KASI 4종 연동 + 캘린더 API, 별보기 격자 배치, 방치 배치 + 알림함, VIIRS 샘플링, 명소 상세·감자 심기 화면, 배포, 베타 | 캘린더가 실제 값으로 뜸, 배고픔 알림 발생, 외부 접속 |

> 2026-09·10 행은 1.0 계획이다. 실제로는 10/31~11/1에 디자인·프론트(홈·지도·캘린더)가 먼저 진행됐고, 백엔드는 골격만 있다. 11월 일정은 백엔드 중심으로 다시 잡는다.

## 5. 로드맵

- **Phase 1 (MVP, ~2026-12)**: 위 MVP 표.
- **Phase 2 (2027 상반기)**: 이벤트 알림 설정, 1 km·500 m 격자와 접근성 요소, 날씨·지형고도 지도 탭(SDK), 앱 내 경로·진입로 메모, 커뮤니티 피드(후기·질문·모임·사진 응모·잡담)와 글 수정·삭제, 장터(채팅 연결), 네이버·이메일 로그인과 계정 연결, 프로필 활동 탭·사진 업로드, 광공해 오버레이(미완 시).
- **Phase 3 (2027 하반기~)**: 네이티브 앱(iOS 우선) + FCM 푸시 + 애플 로그인, 팔로우·추천 정렬, 장비 후기·순위, 우주 뉴스 자동 수집·요약.

## 6. 미결 사항

- 감자 등급 상승 기준(재방문 1회 = 1단계)과 방치 판정(이벤트 2회)의 실제 수치 튜닝.
- "큰 천체 이벤트"의 정의(유성우 극대기·식·슈퍼문만인지, 행성 접근도 포함인지).
- 큐레이션 30곳 목록과 선정 기준.
- 감자 일러스트 8장 + 먹이 아이콘 제작 담당·일정.
- 두 사람의 역할 분담.
- **지도 SDK(카카오 vs 네이버)** — 지형고도 탭을 MVP에 넣을지에 달림. 11월 둘째 주까지 ([ADR-0011](./ADR/0011-map-rendering-hybrid.md)).
- 별보기 점수의 접근성 요소를 MVP에서 광공해 등급 고정값으로 대신할지(현재 안), 도로망까지 넣을지.
- 이달의 사진 선정 규칙(전월 좋아요 1위, 동률·부적절 사진 처리)과 선정자 보상.
- 카카오 개발자 앱 등록, 기상청·천문연구원 API 키, PaaS 계정, R2 버킷.
