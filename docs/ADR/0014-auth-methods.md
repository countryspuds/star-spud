# ADR-0014 로그인 수단: MVP 카카오, 네이버·이메일은 Phase 2 (디자인 선행)

- 상태: 채택 (2026-11-01) — [ADR-0009](./0009-auth-oauth-jwt.md)를 보완한다(대체하지 않음).

## 맥락
ADR-0009는 소셜 OAuth + JWT, MVP는 카카오만으로 정했다. 디자인 작업에서 로그인·온보딩(닉네임·감자 아바타·약관)·이메일 가입·비밀번호 재설정·계정 연결 화면이 만들어졌고, 설정 화면에 "한 계정에 여러 로그인 수단 연결" 구조가 들어갔다.

## 결정
- MVP는 ADR-0009대로 **카카오만**. 온보딩(닉네임 2~12자 · 감자 아바타 · 주로 보는 지역 · 약관)은 MVP에 포함한다.
- 네이버 OAuth와 이메일/비밀번호 로그인은 Phase 2. 단, `users` 테이블은 처음부터 **계정 1 : 로그인 수단 N** 구조(`auth_identities(user_id, provider, provider_uid|email, password_hash?)`)로 만들어 나중에 같은 이메일의 중복 계정 문제를 피한다.
- 프로필 사진은 사용자가 올리거나 감자 아바타를 쓴다. 소셜 프로필 사진은 받지 않는다(개인정보 최소화).

## 결과
- ARCHITECTURE §3 `users`의 `provider, provider_uid`를 `auth_identities`로 분리한다.
- 로그인 화면은 MVP에서 카카오 버튼만 보이고, 이메일 폼은 Phase 2에 켠다(디자인은 캔버스에 있음).
