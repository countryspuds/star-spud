# ADR-0011 지도 렌더링: 도트 격자 + 실제 지도 SDK 하이브리드

- 상태: **제안** (2026-11-01) — 지도 SDK 선택은 미결. 결정 시 [ADR-0001](./0001-kakao-map-sdk.md)을 `superseded`로 바꾼다.

## 맥락
ADR-0001은 "카카오맵 JS SDK 단일 + 핀 색상"으로 지도를 정의했다. 10/31~11/1 디자인 작업에서 서비스의 시각 정체성이 **5 km 격자 도트 지도**(VIIRS 광공해 → 별보기 점수)로 정해졌고, 홈 위젯·지도 첫 탭·시·도/시·군·구 퍼즐 드릴다운이 이 격자 위에 구현됐다(`frontend/src/components/map/MapCanvas.tsx`, `RegionPuzzle.tsx`).

그러나 다음은 도트 격자로 해결되지 않는다.
- **내 위치 기준**으로 주변 명소를 보는 것 — 사용자가 가장 자주 하는 행동. 격자는 전국 개요용이고 도로·지명이 없다.
- 날씨(미세먼지 측정소·강수)와 지형고도는 실제 지도 위에 올려야 읽힌다.
- 명소 상세의 진입로·주차 위치, 길찾기 연결.

## 결정 (제안)
두 렌더러를 **역할로 분리**한다.

| 역할 | 렌더러 | 화면 |
|---|---|---|
| 전국 개요 · "어디가 어두운가" | 도트 격자 (자체 canvas/SVG) | 홈 별보기 위젯, `/map` 별보기 탭, `/map/lp` 광공해 탭, 시·도/시·군·구 퍼즐, 내 감자밭 |
| 내 위치 기준 탐색 · 명소 핀 · 날씨·지형 · 상세 | 지도 SDK | `/map/weather`, `/map/terrain`, `/map/near`(내 위치), `/spots/:id` 지도, 길찾기 |

- 전환 규칙: 도트 지도에서 시·군·구까지 들어가거나 "내 위치" 버튼을 누르면 SDK 지도로 넘어간다. SDK 지도의 핀 색은 ADR-0001대로 **서버가 준 값**(별보기 점수 구간 또는 `good/fair/bad`)만 쓴다.
- 광공해 오버레이(ADR-0002 정적 타일)는 SDK 지도 쪽에 그대로 유효하다. 도트 지도는 타일이 아니라 격자 JSON(`GET /api/v1/grid/starscore?res=5km`)을 쓴다.

**SDK 선택 — 미결.** 비교해 결정한다.

| | 카카오맵 | 네이버 지도 |
|---|---|---|
| 지형도 타입 | 없음 (지형고도 탭은 자체 음영 필요) | `TERRAIN` 내장 |
| 커스텀 타일 오버레이 | 지원 (ADR-0002 전제) | 지원 |
| 로그인·길찾기와 키 통합 | 카카오 OAuth·모빌리티와 한 계정 | 별도 NCP 계정 |
| 모바일 앱 SDK (Phase 3) | 있음 | 있음 |

지형고도 탭을 MVP에 넣으면 네이버가 유리하고, MVP를 ADR-0001 범위(핀 + 광공해 타일)로 좁히면 카카오가 단순하다. **11월 둘째 주까지 결정.**

## 결과
- 프론트 `<MapCanvas>`(도트)와 `<NaverMap>`/`<KakaoMap>`(SDK) 컴포넌트 경계를 유지한다. SDK 컴포넌트는 placeholder 상태.
- 격자 JSON 엔드포인트와 별보기 점수 계산이 백엔드에 추가된다([specs/11](../../specs/11-star-score.md)).
- AGENTS.md의 "카카오맵 JS SDK" 문구는 "지도 SDK(미정, ADR-0011)"로 바꾼다.
