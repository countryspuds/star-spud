# ADR-0012 홈 화면과 정보 구조(IA)

- 상태: 채택 (2026-11-01)

## 맥락
PRD 1.0과 ARCHITECTURE §4는 `/`를 지도로 두고 메뉴를 지도·이벤트·내 감자밭·알림함으로 잡았다. 디자인 작업에서 "오늘 밤 어디 갈까"에 한 화면으로 답하는 **벤토 랜딩**이 홈으로 확정됐고, 메뉴가 재편됐다. 홈과 지도·캘린더는 구현·머지됐다(PR #1, #3, #6).

## 결정
- `/` = 홈(벤토): 이달의 사진 · 별보기 지도 위젯 · 별보기 지수 10일 차트 · 오늘 밤 세부값 · 다가오는 이벤트 3개. 지도는 `/map`.
- 전역 메뉴 6개: **홈 · 지도 · 캘린더 · 프로필 · 커뮤니티 · 장터**. 로그인 후 우측 버튼은 아바타+닉네임.
  - '이벤트' 메뉴는 '캘린더'로, '내 감자밭'은 '프로필' 안의 탭(감자밭 · 활동 · 설정)으로 들어간다.
  - 커뮤니티·장터는 MVP 제외(PRD §4)지만 메뉴 자리는 두고 "준비 중" 페이지로 연결한다. 화면 디자인은 캔버스에 있다.
- 공통 푸터: 서비스 · 도움말(문의·버그 제보·기능 제안·명소 정보 수정) · 정책 · 데이터 출처.
- 상세 치수·토큰은 `docs/FRONTEND_SPEC.md`가 기준이다.

## 결과
- ARCHITECTURE §4 라우팅과 PRD §3·§4를 이 결정에 맞춰 고친다.
- `/events` 목록 화면은 만들지 않고 캘린더(`/calendar`)의 하단 리스트가 대신한다. `/me/potatoes`는 `/me`(프로필 › 감자밭)로.
