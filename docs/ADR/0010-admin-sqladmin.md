# ADR-0010 관리자 도구는 최소 관리자 REST API + 프론트 관리 화면

- 상태: 채택 (2026-09-02) · 갱신 (2026-11-01, 백엔드 Spring Boot 전환으로 sqladmin 대체)

## 맥락
명소 편집, 신고 처리, 이벤트 수동 등록, 장비 마스터 관리에 관리 화면이 필요하다. 후보는 ① 일반 UI에 관리자 권한 버튼, ② 별도 관리자 웹(라이브러리), ③ DB 직접 수정. 처음에는 FastAPI용 `sqladmin`(②)을 골랐으나, 백엔드를 Spring Boot로 바꾸면서 모델 등록만으로 CRUD가 생기는 같은 급의 라이브러리가 없어졌다.

## 결정
백엔드에 최소한의 관리자 REST API(`/api/v1/admin/*`, `users.role = admin`만 접근)를 두고, 프론트에 간단한 관리 화면(`/admin`)을 만든다. 관리 화면은 일반 사용자 UI와 분리된 라우트이며 관리자 외에는 404.

## 결과
- 모델별 CRUD를 직접 만들어야 하므로 MVP 비용이 sqladmin보다 크다. MVP는 `specs/09`의 표에 있는 모델·컬럼만 최소로 만든다.
- 복잡한 워크플로(신고 일괄 처리 등)는 Phase 2에 그 화면만 추가한다.
- 일반 사용자 UI에는 관리 기능을 넣지 않는다.
