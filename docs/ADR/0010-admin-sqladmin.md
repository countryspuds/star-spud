# ADR-0010 관리자 도구는 sqladmin

- 상태: 채택 (2026-09-02)

## 맥락
명소 편집, 신고 처리, 이벤트 수동 등록, 장비 마스터 관리에 관리 화면이 필요하다. 후보는 ① 일반 UI에 관리자 권한 버튼, ② 별도 관리자 웹(라이브러리), ③ DB 직접 수정.

## 결정
FastAPI용 `sqladmin`으로 별도 관리자 웹을 `/admin` 경로에 붙인다. 접근은 `users.role = admin`인 계정의 세션으로 제한한다.

## 결과
- 모델을 등록하기만 하면 CRUD가 생겨 MVP 비용이 거의 없다.
- 복잡한 워크플로(신고 일괄 처리 등)가 필요해지면 그 화면만 커스텀으로 만든다.
- 일반 사용자 UI에는 관리 기능을 넣지 않는다.
