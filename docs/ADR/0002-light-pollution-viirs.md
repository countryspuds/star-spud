# ADR-0002 광공해는 VIIRS 좌표 샘플링 + 정적 타일

- 상태: 채택 (2026-09-02)

## 맥락
명소별 보틀 등급과 지도 오버레이가 필요하다. 후보는 ① 수동 입력, ② VIIRS 야간광 래스터를 직접 처리, ③ 상용 광공해 지도 서비스. 수동 입력은 팀이 거부했고(지식 부족, 확장 불가), 상용 서비스는 라이선스·비용이 불확실하다.

## 결정
NASA/NOAA가 공개하는 VIIRS 야간광 연간 합성 래스터를 사용한다.
1. **좌표 샘플링(MVP 필수)**: 명소 좌표의 복사휘도 값을 읽어 보틀 등급으로 근사 변환하는 스크립트.
2. **정적 타일 오버레이(MVP 스트레치, 늦어도 Phase 2)**: GDAL로 타일 이미지를 생성해 오브젝트 스토리지에 올리고 카카오맵 타일셋으로 표시. 타일 서버를 두지 않는다.

## 결과
- 서버 런타임에 GIS 의존성이 없다. 연 1회 오프라인 처리.
- 보틀 등급은 근사치다. 명소 상세에 "위성 데이터 기반 추정" 문구를 단다.
- 휘도→보틀 변환 공식과 색상 램프는 스크립트에 상수로 두고 튜닝한다.
- 오버레이 순서는 샘플링 뒤로 둔다. 11월 일정이 밀리면 오버레이를 먼저 뺀다.
