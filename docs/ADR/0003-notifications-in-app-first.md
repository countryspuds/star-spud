# ADR-0003 MVP 알림은 앱 내 알림함, 푸시는 FCM으로 앱 단계에

- 상태: 채택 (2026-09-02)

## 맥락
감자 배고픔 알림과 이벤트 알림이 필요하다. README 초안은 서비스워커 웹푸시를 계획했다. 팀은 최종적으로 네이티브 앱을 만들 계획이며, MVP에서는 푸시 인프라를 만들지 않기로 했다.

## 결정
- MVP: `notifications` 테이블과 앱 내 알림함만 구현한다. 알림 생성 로직은 채널과 무관하게 작성한다.
- 앱 단계(Phase 3): FCM을 단일 푸시 백엔드로 도입한다. FCM은 웹·iOS(APNs 경유)·Android를 같은 방식으로 다루므로 `device_tokens(platform)`만 추가하고 발송 서비스를 붙인다.
- 이메일은 필요해질 때 보조 채널로 검토한다.

## 결과
- MVP에서 재방문 유도 효과는 접속했을 때만 작동한다. 이 한계는 인지하고 수용한다.
- 알림 도메인 모델(type, payload)은 처음부터 푸시 페이로드로 변환 가능하게 설계한다.
- 서비스워커 푸시 코드는 작성하지 않는다.
