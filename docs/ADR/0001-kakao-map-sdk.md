# ADR-0001 지도 SDK는 카카오맵 단일

- 상태: 채택 (2026-09-02)

## 맥락
README 초안에 카카오맵과 네이버지도가 함께 적혀 있었다. 두 SDK를 모두 지원하면 지도 관련 코드가 두 벌이 되고, 커스텀 타일 오버레이·마커·이벤트 처리도 각각 검증해야 한다.

## 결정
웹은 카카오맵 JS SDK만 사용한다. 네이버지도 SDK는 제거한다. 길찾기도 카카오(딥링크 → Phase 2에 카카오 모빌리티 API)로 통일한다.

## 결과
- 로그인도 카카오 OAuth를 기본으로 하여 개발자 계정·키 관리가 한 곳으로 모인다.
- 광공해 오버레이는 카카오맵 커스텀 타일셋 기능에 의존한다.
- 네이티브 앱에서는 카카오맵 iOS/Android SDK를 쓴다. 웹과 SDK가 다르므로 핀 색상 등 표시 규칙은 API 응답에 담고 클라이언트는 그리기만 한다.
